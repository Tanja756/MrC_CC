# MrC Check — Мобильное приложение для управления заявками

Мобильное приложение для управления складскими заявками, предназначенное для сотрудников компании МРЦ.

## Основные возможности

- Управление заявками (активные, свободные, закрытые)
- Поиск, сортировка и фильтрация заявок
- Закрепление важных заявок (пины)
- Групповые операции через множественный выбор
- Геолокация при завершении заявки
- Уведомления о приближающихся сроках
- Интеграция с 1С
- Адаптивный интерфейс, светлая и тёмная темы

## Технические требования

- Android 6.0+ (API level 23+)
- Разрешения: интернет, геолокация, хранилище

## Установка

1. Скачайте APK из [Releases](https://github.com/Tanja756/MrC_CC/releases)
2. Установите на устройство
3. При первом запуске настройте подключение к серверу 1С

## Безопасность

- Данные хранятся в зашифрованном виде
- Пароли сохраняются в защищённом хранилище Android
- Креденшелы Яндекс.Диска исключены из репозитория через `.gitignore`

## Разработка

- Android Studio Arctic Fox+
- JDK 11, Gradle 7.0+
- Kotlin, AndroidX, Retrofit, Material Design Components
