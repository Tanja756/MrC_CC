# MrC Check — Мобильное приложение для управления заявками

![Android](https://img.shields.io/badge/Platform-Android-green.svg)
![Kotlin](https://img.shields.io/badge/Language-Kotlin-blue.svg)
![License](https://img.shields.io/badge/License-Proprietary-red.svg)

Мобильное приложение для управления складскими заявками, предназначенное для сотрудников компании МРЦ.

## Основные возможности

✅ **Управление заявками**
- Просмотр активных, свободных и закрытых заявок
- Сортировка по сроку, дате создания и приоритету
- Поиск и фильтрация заявок по различным параметрам
- Завершение заявок с прикреплением файлов и указанием геолокации

✅ **Закрепление заявок (пины)**
- Возможность закреплять важные заявки для быстрого доступа
- Закреплённые заявки отображаются в специальном разделе
- Визуальная индикация закреплённых заявок (иконка булавки)
- Управление пинами через контекстное меню или иконку на карточке заявки

✅ **Множественный выбор**
- Режим выбора нескольких заявок для групповых операций
- Активация через долгое нажатие на заявку
- Отображение чекбоксов в режиме выбора

✅ **Геолокация**
- Автоматическое определение местоположения при завершении заявки
- Сохранение координат в локальной базе данных
- Визуальная индикация наличия геоданных для закрытых заявок

✅ **Интеграция с 1С**
- Подключение к серверу 1С:Предприятие
- Получение актуальных данных о заявках, клиентах и складах
- Отправка данных о завершённых заявках

✅ **Удобный интерфейс**
- Адаптивный дизайн для разных размеров экранов
- Светлая и тёмная тема
- Уведомления о приближающихся сроках выполнения
- Возможность прикрепления файлов к заявкам

## Технические требования

- **Android версии 6.0 и выше** (API level 23+)
- Разрешение на доступ к интернету
- Разрешение на доступ к геолокации (для фиксации местоположения)
- Разрешение на доступ к хранилищу (для прикрепления файлов)

## Установка

1. Скачайте APK-файл из раздела [Releases](https://github.com/Tanja756/MrC_CC/releases)
2. Установите его на устройство Android
3. При первом запуске настройте параметры подключения к серверу 1С

## Настройка подключения

Для работы приложения необходимо указать параметры подключения к серверу 1С:

1. Откройте экран настроек (иконка шестеренки)
2. Укажите:
   - Адрес сервера (IP или домен)
   - Порт сервера
   - Имя базы данных
   - Логин и пароль
3. При необходимости настройте параметры прокси-сервера
4. Сохраните настройки

## Использование

### Работа с активными заявками
- На главном экране отображаются все активные заявки
- Для просмотра описания нажмите кнопку **«Описание»**
- Для завершения заявки нажмите кнопку **«Завершить»** и следуйте инструкциям
- При завершении заявки можно прикрепить файлы и указать комментарий

### Просмотр закрытых заявок
- Перейдите на вкладку **«Закрытые заявки»**
- Используйте поиск для фильтрации заявок
- Зелёный значок 📍 указывает на наличие геоданных
- Красный значок 📍 указывает на отсутствие геоданных

### Работа со свободными заявками
- Перейдите на вкладку **«Свободные заявки»**
- Нажмите **«Взять»** для назначения заявки на себя
- Заявка переместится в активные

### Закрепление заявок
- Нажмите на иконку булавки 📌 на карточке заявки или выберите пункт **«Закрепить»** в контекстном меню (долгое нажатие)
- Закреплённые заявки отображаются в активных с приоритетом

## Безопасность

- Все данные хранятся в зашифрованном виде
- Пароли сохраняются в защищённом хранилище Android
- Подключение к серверу осуществляется через защищённое соединение
- Поддерживается работа через прокси-серверы
